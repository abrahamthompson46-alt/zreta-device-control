Applications

Device Owner only. One Android package name per line, such as com.example.game. System packages and the Zreta app itself are skipped by the phone.

Camera and device

Device Owner only. Unchecked means the restriction is not in the policy, so a later publish clears it on the phone.

Calls and messaging

Device Owner only. These block every outgoing call or every SMS. They do not block one phone number, and they do not read or record calls or messages.

Internet

Configuration locks stop the person from changing those settings. They do not, by themselves, switch Wi-Fi or mobile data off. The domain list is a local DNS blocklist: classic UDP DNS only, not always-on, and it fails open when the filter VPN is down.

Screen time

One local bedtime window. The end time is exclusive. This is not a daily minute limit. The phone checks the window when it applies policy, which can be delayed.

Location

This checkbox records location.collection_desired only. It does not turn GPS on. Collection still requires the location switch on the device page, the phone disclosure, and Android permission.

Review before publish

Saving a draft does not send anything to phones. Publishing replaces the current published version. Assigned devices pull the new document and enforce it.
